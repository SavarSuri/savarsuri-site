02 — work

Things I've built.

GhostED

● LIVE

Students anonymously share what actually happened when they applied to internships — ghosted, rejected, interviewed, offered. Aggregate ghost rates, offer rates, and per-company breakdowns. I built it because I was dozens of applications deep with no idea what was normal.

Security note — I audited my own code and found a stored XSS: user-submitted fields were rendered straight into innerHTML. All output is now HTML-escaped, free-text fields are length-capped at the database layer, and the Supabase anon key is scoped by row-level security to SELECT and INSERT only — no UPDATE, no DELETE.
