02 · SYSTEMS

Two things I built that run without me watching them.

GHOSTED● LIVE

Anonymous internship outcome tracker

JAVASCRIPT · SUPABASE · POSTGRESQL · VERCEL · MAY 2026

Students apply to dozens of internships and hear nothing. GhostED collects those outcomes anonymously — tagged by school tier, GPA band and class year — and computes four live metrics over them: submission volume, ghost rate, offer rate, and companies covered, with filterable per-company breakdowns.

I audited my own source and found a stored XSS. Every user-supplied field was being written into innerHTML, so a crafted company name would have executed in every visitor's browser. I escaped all rendered output, added database-level length constraints, and confirmed row-level security scoped the public key to SELECT and INSERT only. Three layers, because any one of them alone can be got around.

LEAD-RESPONSE PIPELINE● LIVE

Four-stage automation, unattended

N8N · ANTHROPIC API · WEBHOOKS · GMAIL API · AUG 2026

A homeowner with a dead furnace messages four companies and hires whoever answers first. Small contractors lose that race because the form lands in an inbox nobody watches. This reads the form, normalizes the fields, calls the model, and sends a reply referencing the customer's actual stated problem — in under a minute, with nobody at the keyboard.

I engineered the system prompt for deterministic tone and output structure, handled authentication, JSON payload construction and error states across three third-party services, then self-hosted the runtime after the trial expired and debugged a live production pipeline with no logging available.
